Rux99 · Android setup

  1. Install and start Shizuku using wireless debugging (Android 11+) or a computer with ADB.
  2. Open Rux99 and tap Connect Shizuku. Allow Rux99 in the Shizuku permission prompt.
  3. Wait for Connected, then use the boost button. Unsupported commands show their actual errors. Performance improvements depend on your phone.

Android app required. This website cannot change phone settings.

Boost disables Android animations, requests performance mode, exempts Free Fire from battery restrictions, clears background apps and compiles the game. These changes can increase battery use and heat. Restart Shizuku after a reboot. Free Fire package: com.dts.freefireth.

Restore sets animations to 1×, disables fixed performance mode, selects standard game mode and removes the battery exemption. It does not restore custom previous settings or undo compilation.
